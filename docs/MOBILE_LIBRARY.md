# 出门后听电脑曲库

已配对的电脑可以保存外网地址；歌曲也可以先下载到手机。Android Auto 读取手机曲库和已连接的电脑曲库，选歌后在手机播放。

## 下载与断网播放

长按电脑曲库中的歌曲，选择 **下载到手机**。进入 **音乐库 → 离线音乐** 查看进度、暂停、继续、播放或移除。

完成的下载加入“此手机”曲库，重新扫描音乐文件夹会保留。手机播放电脑曲库中的同一音源时优先使用已完成下载；电脑未连接时也能播放。忘记电脑会移除配对关系，已完成下载保留，可在离线音乐中删除。播放中的文件须先停止才能删除。

默认下载额度为 5 GiB，可在“网络与存储”中选择 1／5／10／20 GiB；单个文件和所有下载占用都受额度限制。任务最多 500 个。后台传输通过带进度通知的前台服务运行，系统终止或重启后保留可续传任务，点“继续”恢复。

下载固定电脑的 `serverId`、`libraryId`、音源 ID 和文件版本。断点续传只接受同一版本；原文件改变时提示移除旧任务后重新下载。部分文件不会出现在曲库，也不能播放。下载文件不进入 Android 云备份或设备迁移。

支持范围沿用电脑原文件串流：FLAC、MP3、AAC／ALAC、WAV、OGG／Opus、AIFF、APE、WavPack 等。CUE 子轨、SACD／容器子轨和需要 Provider 授权的云端歌曲仍由各自播放路径处理。这里的下载是明确选择的歌曲，不会自动同步整个电脑曲库。

## 移动网络

**离线音乐 → 网络与存储** 提供两个独立开关：

- **允许计费网络下载**：默认关闭；网络变为计费网络后，下一次读取停止传输，任务保留，回到非计费网络后可继续。
- **计费网络播放电脑音乐**：保留原先允许串流的默认行为，可手动关闭；已缓冲的少量音频可继续播放，下一次网络读取按新设置执行。

这些开关管理电脑原文件串流与离线下载。网易云和其他 Provider 的质量、下载授权仍由对应音源管理。已下载音乐无需网络。

## 保存外网地址

在 **设置 → 连接电脑** 找到已配对电脑，点 **外网地址**，填写可达的 VPN 地址或 HTTPS 主机与端口。保存后点 **通过外网连接**；清空地址并保存可移除配置。

优先使用已经配置的私人 VPN。公网入口需要操作者提供网络可达性；应用保存地址并复用原配对身份，不提供中继或自动配置路由器。若使用转发，必须保持 Server 的端到端 TLS 证书；终止 TLS 并换成其他证书的反向代理会被原配对证书检查拒绝。首次配对仍须核对手机验证码，由桌面或 Server 管理端批准。

自动恢复会尝试发现地址、上次地址和保存的外网地址。网络不可达可尝试下一个地址；证书变化、身份不符或授权失效会停止并提示重新连接，不向另一个 Server 发送旧凭据。外网地址变更不改变播放队列或声音输出。

## Android Auto

车载媒体浏览入口提供 **此手机的音乐** 和已连接电脑，支持按歌曲、艺人、专辑文字搜索。下载完成的歌曲属于手机曲库，可在断网时选播。选歌明确切换为手机发声，继续使用原生 FFmpeg／DSP 与手机 Core 队列；系统通知、锁屏和耳机按键保留原入口。

浏览器只取得本次服务发出的歌曲标识。外部客户端提供的任意 URL 或文件路径不会成为播放来源。电脑离线时先在手机连接，或从手机曲库选择已经下载的副本。
